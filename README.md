# Odin Recipes

This is my first project from The Odin Project. I created a simple recipe website using HTML. The website has a homepage with links to three recipes: Tater Tot Casserole, Spaghetti, and Chocolate Chip Cookies.

## Skills Demonstrated

During this project, I practiced:

- Creating HTML pages using boilerplate
- Using headings and paragraphs
- Adding images with alt text
- Creating ordered and unordered lists
- Linking multiple HTML pages together
- Organizing files and folders
- Using Git and GitHub to track my progress
- Writing meaningful Git commit messages

## What I Learned

I learned how to build a website with multiple pages and connect them using relative links. I also gained more experience writing HTML in VS Code and using Git to save my progress.

This project helped me practice building a website independently using the skills I've learned from The Odin Project.
